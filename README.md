# LAPD Department Organization Site

Static GitHub Pages-ready website.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `.nojekyll`, and the `images/` folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Save and wait for GitHub Pages to publish.

Keep image paths relative, for example `images/jim-berry.png`.
